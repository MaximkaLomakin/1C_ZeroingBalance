# Обнуление остатков и резервов (УНФ 3.0)

Обработка полностью обнуляет остатки и резервы на выбранном складе по выбранной организации.

Подходит для **Управление нашей фирмой 3.0** (проверялось на 3.0.13).

## Что делает

1. Снимает резервы по заказам покупателей.
2. Обнуляет все остатки на складе (и плюсы, и минусы), включая резерв.
3. Обновляет остатки в списке номенклатуры («Свободно» / «В резерве»).

| Имя | Тип |
|-----|-----|
| Организация | Организации |
| Склад | Структурные единицы |
| ДатаОбнуления | Дата |
| Корреспонденция | План счетов «Управленческий» |
| СниматьРезервы | Булево |
| СписыватьОстатки | Булево |
| ПроводитьДокументы | Булево |
| ЛимитСтрокВДокументе | Число (10, 0) |

3. Добавьте табличные части:

**Резервы:** Номенклатура, Характеристика, Партия, ЗаказПокупателя, Количество  

**Остатки:** Номенклатура, Характеристика, Партия, Количество, Сумма

4. В модуль объекта вставьте код из `МодульОбъекта.bsl`.
5. Создайте основную форму, перетащите на неё поля и таблицы из `Объект`, добавьте кнопки **Заполнить** и **Выполнить обнуление**.
6. В модуль формы вставьте код из `МодульФормы.bsl`.
7. Сохраните как `.epf`.

## Как подключить в базе

**Настройки → Печатные формы, отчеты и обработки → Дополнительные отчеты и обработки → Добавить из файла.**
